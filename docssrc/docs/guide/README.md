# 操作指南

## 启动与登录

在项目根目录执行以下命令启动服务：

```bash
python src/backend/launch.py
```

终端会输出前端访问地址（默认 `http://localhost:5173`）和默认账号（`admin` / `admin`），用户可以在浏览器中打开该地址。

![系统启动](/assets/system_launch.png)

可看到登录界面：

![登录界面](/assets/login.png)

在登录界面输入用户名和密码，认证通过后进入主界面。

## 主界面与应用管理

登录后主界面左侧为功能面板，右侧为内容窗口区域。左侧面板顶部三个入口用户可以随时切换：

- **启动器**（+）：展示已安装应用列表，用户点击应用图标即可创建一个线程开始工作。系统预装 calc.App（计算器）和 snake.App（贪吃蛇）两个应用。
- **安装器**（📦）：用户可以在此安装新应用（支持文件夹和 ZIP 包）、卸载不需要的应用、或清空应用的持久化数据。
- **通知中心**（🔔）：用户可以查看系统通知，支持单条删除和一键清空。

功能按钮下方是**线程列表**，显示所有运行中的线程。用户可以点击列表项在各窗口间切换，切换不会中断后台工作。底部按钮可折叠面板以获得更大工作区。

![主界面](/assets/browse_apps.png)

![创建线程](/assets/start_thread.png)

## 线程与窗口

用户在启动器中点击应用时，系统为该应用创建一个逻辑线程：启动应用的后端进程、打开内容窗口加载前端页面、线程出现在左侧列表中。用户可以对同一应用创建多个线程，各自独立运行互不干扰。

每个线程窗口顶部有标题栏，显示线程名称和关闭按钮（×）。用户可以双击标题栏重命名线程，便于区分多个并行工作。点击 × 关闭线程时，系统终止该线程的后端进程，内存中的临时状态随之丢失；已经持久化到磁盘的数据（如贪吃蛇排行榜）不受关闭影响。

## 内置例程

系统预装两个示例应用，用户可以直接打开使用，也展示了两种典型的前后端交互模式：

- **calc.App（计算器）**：请求-响应模式。前端发送表达式，后端求值返回结果。计算历史保存在内存中，关闭线程后历史不保留。

![计算器](/assets/calc.png)

- **snake.App（贪吃蛇）**：数据持久化模式。游戏逻辑在浏览器中运行，游戏结束后用户可以将分数提交到后端排行榜；排行榜通过文件锁保证多线程并发写入安全，数据持久保存。

![贪吃蛇](/assets/snake.png)

## 关闭服务

服务器可以持续运行，用户可以随时关闭浏览器窗口而不影响后台工作。需要完全停止服务时，在运行 launch.py 的终端按 **Ctrl+C**，系统关闭（终止线程进程、释放端口）。请勿在数据未完成写入磁盘或端口未释放的时候关闭服务，否则可能导致数据丢失。

关闭后，持久化数据（排行榜、应用安装状态）完整保留；内存状态（计算历史、未提交分数）丢失；所有线程被销毁，下次启动需重新创建。
