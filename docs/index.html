关于 Nano Desktop OS

Nano Desktop OS 是一个以 逻辑线程编程（Logical Thread Programming） 为范式的通用平台，将后端与前端收拢为一个整体来组织应用的运行。系统将工作组织为多个并行的逻辑线程，每个线程承载一个正在进行的工作会话，拥有独立的状态、逻辑和界面；用户通过浏览器进入线程的内容窗口与应用交互，可在多个窗口间自由切换而不中断后台工作。

在 Nano Desktop OS 中，一个应用由 后端（Backend） 和 前端（Frontend） 两部分构成：后端是一个在Python解释器中运行的程序，在后台独立进程中执行，负责业务逻辑、数据计算与持久化；前端是HTML/JavaScript页面的程序，在浏览器中加载运行，负责呈现与交互。前后端之间由系统内置的 线程对象代理（Thread Objects Broker） 提供结构化的互操作通道，使不同环境中的程序能够像本地对象一样相互调用方法；同时提供基于应用名称的私有数据存储，使每个应用的数据与应用本身绑定。应用接入遵循一个极简的规约——放入指定目录即可运行。
